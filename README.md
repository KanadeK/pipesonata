# PipeSonata

PipeSonata turns CI workflow timing, failure, and concurrency into an actionable visual score.

The project is under active development toward `v0.1.0`. It is designed as a local-first React
application: imported workflow data stays in the browser unless the user explicitly chooses an
online adapter.

## Development

```bash
npm ci
npm run lint
npm run typecheck
npm run test:coverage
npm run build
```

See [Architecture](docs/ARCHITECTURE.md), [privacy and security](docs/PRIVACY_AND_SECURITY.md), and
the [public repository scan](docs/COMPETITOR_SCAN.md).
