## [0.1.0] - 2026-07-23

- Repository foundation, deterministic quality gates, and public-project governance.
- Validated GitHub Actions run parsing, dependency critical paths, concurrency metrics, engineering
  hotspots, stable score notes, and credential-safe exports.
- Bundled fast, serial-bottleneck, and flaky MIT fixtures plus combined-file and GitHub run/jobs
  adapters.
- Delivered the responsive analysis workbench with D3 timing score, optional WebAudio playback,
  local file import, theme controls, and SVG, PNG, MIDI-like JSON, and report exports.
- Added production-browser coverage for deterministic fixtures, local imports, four real downloads,
  keyboard navigation, theme persistence, reduced motion, and narrow screens.
- Completed English and Simplified Chinese guides, executable input and output references, a
  generated production screenshot, demo artifacts, and a reproducible core benchmark.
- Added locked CI, dependency and credential auditing, verified Pages deployment, tag release
  automation, versioned tar archives, CycloneDX SBOM, provenance, SHA-256 checksums, and extracted
  browser smoke testing.
- Hardened the credential scanner and source packager against deleted index entries during
  cross-platform file renames, backed by a temporary Git repository regression test.
- Switched tar creation to workspace-relative paths and added a non-ASCII workspace regression test
  after Windows `bsdtar` rejected an absolute release path.
