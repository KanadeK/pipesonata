# PipeSonata v0.1.0

PipeSonata v0.1.0 is the first public release of the local-first CI timing instrument.

## Highlights

- Import a combined GitHub Actions run fixture or a standard run/jobs response pair.
- Inspect normalized job and step timing, queueing, attempts, retries, failures, observed
  concurrency, dependency critical path, repeated installs, and unstable work.
- Read the same deterministic analysis as a D3 execution score or opt-in WebAudio performance.
- Export accessible SVG, 2x PNG, MIDI-like note JSON, and a credential-redacted Markdown report.
- Start offline with three synthetic MIT fixtures: fast fan-out, serial bottleneck, and flaky browser
  suite.

## Quality evidence

- 35 Vitest unit and integration tests.
- 5 real Chromium E2E paths covering fixtures, import, error preservation, four downloads, keyboard
  focus, theme persistence, reduced motion, and a 390 px viewport.
- Core coverage baseline: 99.01% lines, 100% functions, 90.5% branches, 99.04% statements.
- Official npm advisory audit: 0 vulnerabilities at release preparation.
- Extracted static release archive loaded again in Chromium before publication.

## Privacy boundary

The shipped application is static and has no upload endpoint, account, analytics, advertising, or
persistent workflow-data store. Imported files remain in the browser tab. Text reports redact common
credential patterns, but repository names, commit identifiers, actors, internal labels, SVG, PNG,
and note JSON still require human review before sharing.

## Known limits

- One workflow run at a time; no historical comparison or automatic GitHub polling.
- Explicit `needs` metadata is required for an exact dependency critical path. Without it, the
  longest observed job is labeled as a lower bound.
- Runs with more than 100 jobs require callers to merge paginated GitHub jobs responses.
- The note JSON is an interchange schedule, not a Standard MIDI File.
- PNG export depends on browser canvas support; audio is an interpretive aid, not an accessibility
  replacement.

The next milestone targets historical comparison, a short-lived minimum-scope GitHub adapter,
Standard MIDI File export, richer accessible narration, and Web Worker analysis for large graphs.
